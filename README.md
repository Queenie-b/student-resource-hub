# Project Overview

A platform designed to help students share and discover learning resources📚

# Problem Being Solved

For some students, it may be very hard or stressful to look for student resources. I, personally, find the process very arduous most times🫩.

This project is designed to enable students to help each other. It solve the problem of looking for study resources, and in turn one can decide to help the community by also adding resources.

You can also join the discussion🌐 to ask for help for a problem, and other students can help.
